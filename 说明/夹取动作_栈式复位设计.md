# 夹取动作 + 栈式复位 · 设计 / 落地说明

> **状态：已按你的确认落地到代码。** 本文档与 [main.c](../User/main.c) 里的 `grab_run_once()` 实现一致，作为现场对照表使用。
>
> 采纳的决策：
> 1. 复位**不把空夹爪再合一次**（放开物料那一步不记入撤销栈）；
> 2. 升降电机速度用默认（30 RPM / 加速度档 100）；
> 3. **PA11 中止后停在原地**，不自动复位、不自动找姿态；
> 4. 复位阶段同样可被 PA11 中止（中止后手动摆到安全位）；
> 5. 升降电机的 1000 脉冲按 **上电位置 = 0 的绝对位置**。

## 1. 参与部件

| 部件 | 接口 | 地址 / 通道 | 方向约定 | 角度 / 行程 | 初始位 |
|---|---|---|---|---|---|
| 升降舵机 | PC7 / TIM3_CH2 | `SERVO_LIFT` | 角度↑ = 抬臂 | 0~270° | **90°** |
| 夹爪舵机 | PC8 / TIM3_CH3 | `SERVO_GRIP` | 65° 张开 → 110° 夹紧 | 0~270° | **65°** |
| 旋转舵机 | PC9 / TIM3_CH4 | `SERVO_ROT` | 240° 待机位 → 80° 车上 | 0~270° | **240°** |
| 升降步进电机 | USART1，地址 **6** | 张大头闭环，13 字节位置帧 | **CCW(0x01) = 升高**，CW(0x00) = 下降 | 绝对脉冲（上电位置 = 0） | 0 |
| 物料盘电机 | 地址 5 | —— | —— | —— | **本动作完全不碰** |

脉宽基准（270° 型，500~2500 us ↔ 0~270°）：

| 角度 | 65° | 70° | 80° | 90° | 110° | 170° | 240° |
|---|---|---|---|---|---|---|---|
| 脉宽 | 981 | 1019 | 1093 | 1167 | 1315 | 1759 | 2278 us |

## 2. 正向动作（PA8 触发，6 步）

| # | 部件 | 动作 | 参数 | 等待 | OLED 第 1 行 / 日志 |
|---|---|---|---|---|---|
| 1 | 升降舵机 | 90° → **70°** | 贴近地面 | 800 ms | `GRAB 1/6 LIFT70` |
| 2 | 夹爪舵机 | 65° → **110°** | 夹起物料 | 800 ms | `GRAB 2/6 GRIP110` |
| 3 | **升降电机(6)** | **绝对位置 1000 脉冲，CCW** | 抬起物料 | 1000 ms | `GRAB 3/6 MOT1000` |
| 4 | 升降舵机 | 70° → **170°** | 抬高 | 800 ms | `GRAB 4/6 LIFT170` |
| 5 | 旋转舵机 | 240° → **80°** | 转到车上 | 800 ms | `GRAB 5/6 ROT80` |
| 6 | 夹爪舵机 | 110° → **60°** | 放开物料（**不记入撤销栈**） | 800 ms | `GRAB 6/6 GRIP60` |

### 2.1 第 3 步实际发出的 13 字节帧

```
06  FD  01  00 1E  64  00 00 03 E8  01  00  6B
│   │   │   └─┬─┘  │   └────┬────┘  │   │   └─ 校验 0x6B
│   │   │     │    │        │       │   └──── 立即执行（不等同步帧）
│   │   │     │    │        │       └──────── 绝对位置模式（上电位置 = 0）
│   │   │     │    │        └──────────────── 1000 脉冲（0x03E8）
│   │   │     │    └───────────────────────── 加速度档 100
│   │   │     └────────────────────────────── 速度 30 RPM
│   │   └──────────────────────────────────── CCW = 升高
│   └──────────────────────────────────────── 位置模式 0xFD
└──────────────────────────────────────────── 地址 6（跑之前先 motor_enable_addr(6)）
```

回原位那一帧只有两处不同：`06 FD 00 … 00 00 00 00 …`（CW 下降、目标绝对 0）。

## 3. 栈式复位（正向跑完自动执行）

### 3.1 规则

> **每执行一个动作，就把它的"反向动作"压栈；复位时从栈顶一个个弹出执行（后进先出）。**

所以复位顺序 = 正向动作的**倒序**：最后做的第一个退，最先做的最后退。
栈是执行时自动生成的（[main.c](../User/main.c) 的 `grab_record_undo()`），以后改第 2 节的表，复位顺序自动跟着变。

### 3.2 记录内容

| 动作类型 | 压栈内容 |
|---|---|
| 舵机 | `(哪一路, 执行前的实际角度)` —— 用 `Servo_GetAngle()` 现取，角度微调也被正确带回 |
| 升降电机 | 回 `LIFT_MOTOR_HOME = 0`（上电位置），方向 CW 下降 |

### 3.3 正向 → 复位对应关系

| 正向顺序 | 动作 | 是否压栈 | 复位顺序 |
|---|---|---|---|
| 1 | 升降 90→70 | 是 → 升降回 90 | **R5**（最后退） |
| 2 | 夹爪 65→110 | 是 → 夹爪回 65 | **R4** |
| 3 | 升降电机 → 1000 | 是 → 电机回 0 | **R3** |
| 4 | 升降 70→170 | 是 → 升降回 70 | **R2** |
| 5 | 旋转 240→80 | 是 → 旋转回 240 | **R1**（第一个退） |
| 6 | 夹爪 110→60 | **否**（放开物料不复位） | —— |

### 3.4 实际复位序列（5 步，栈顶 → 栈底）

| # | 部件 | 动作 | 等待 |
|---|---|---|---|
| R1 | 旋转舵机 | 80° → **240°** | 800 ms |
| R2 | 升降舵机 | 170° → **70°** | 800 ms |
| R3 | 升降电机(6) | 绝对 **0**（CW 下降） | 1000 ms |
| R4 | 夹爪舵机 | 60° → **65°** | 800 ms |
| R5 | 升降舵机 | 70° → **90°** | 800 ms |

结束时：旋转 240° / 升降 90° / 夹爪 65° / 升降电机 0 —— **与上电安全位一致，可以直接下一次夹取**。
注意夹爪是从 60° **直接**到 65°，不会先合到 110°（这就是"不把空夹爪再合一次"）。

### 3.5 顺序上的考虑

- R1 先把臂转回 240° 待机位，R3 再让升降平台下降 → 不在车/物料上方下降；
- R4 夹爪回初始位在平台下降之后，此时臂已离开车体；
- R5 最后把升降舵机抬回 90°，机构回到完全张开的待机姿态。

## 4. 时序

| 阶段 | 内容 | 估算 |
|---|---|---|
| 正向 | 5 次舵机等待（5×800）+ 电机 1000 ms | **5.0 s** |
| 复位 | 5 次舵机等待（5×800）+ 电机 1000 ms | **5.0 s** |
| 一轮 | 正向 + 复位 | **≈ 10 s** |

电机 1000 脉冲在 30 RPM 下约 0.63 s，等 1000 ms 留了加减速余量。

## 5. 中止与异常

### 5.1 PA11 中止（正向 / 复位都生效）

- 检查点：每次等待里每 1 ms 查一次；
- 中止后 **停在原地**：不自动复位、不自动找姿态，画面显示 `ABORT BY PA11`，串口打 `[RUN] ABORT BY PA11 - stopped in place, fix pose by hand`；
- 中止发生在**升降电机运动途中**时，会补发一帧立即停止 `06 FE 98 00 6B`，避免它继续走完；
- 升降电机用**绝对位置**，即使中途停住，下一次按 PA8 仍会去绝对 1000 / 绝对 0，不会累积误差（除非断电或手推过超过了行程，才需要重新找零）。

### 5.2 升降电机的"到位"判断

用**固定 1000 ms**，不轮询 `0x3A`，所以 [Serial.c](../Hardware/Serial.c) 的回包帧头保持 `0x01~0x05` 不动。
如果以后要更紧凑，可以改成轮询地址 6 的 `0x3A`（需要把回包帧头放宽到 `0x06`）。

### 5.3 其它

- 地址 6 上电默认失能，每次按 PA8 后会先 `motor_enable_addr(6)` 再动作；
- 若电机堵转/丢步，闭环驱动器会自己报错，这里只负责发帧。

## 8. 上板验证清单

1. 示波器/舵机测试仪量 PC7/PC8/PC9：20 ms 周期，上电 1167 / 981 / 2278 us。
2. 单测升降电机：`motor_enable_addr(6)` 后发 `06 FD 01 00 1E 64 00 00 03 E8 01 00 6B`，确认**方向是升**、行程 1000 脉冲；再发 `06 FD 00 00 1E 64 00 00 00 00 01 00 6B` 确认回原位。
3. 空载按 PA8：核对 6 步顺序、方向、OLED 文案（`GRAB n/6` → `BACK n/5`）。
4. 空载看复位：确认结束时三个舵机回到 240/90/65、升降电机回 0。
5. 带物料跑一轮，再跑第二轮：确认第二轮起始姿态和第一轮一致。
6. 中途按 PA11（分别在正向和复位阶段）：确认停在原地、串口提示手动摆位。
