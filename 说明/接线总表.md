# 接线总表（STM32F103C8T6 ↔ K230 ↔ 步进驱动 ↔ 舵机 ↔ OLED）

> 对应固件：`User/main.c` 里 `DEBUG_MODE = DEBUG_MODE_VISION`（视觉链路测试，只显示不动作）。
> 所有引脚都是现场实测确认过的，**改代码前先看这份表**。

---

## 0. 一句话总览

```
                    ┌──────────────────────────────┐
                    │  USB-TTL (调试 / 烧录)        │
                    └───────┬──────────┬───────────┘
                            │ TX       │ RX
                            ▼          ▲
   ┌───────────┐      ┌─────────────────────────┐      ┌──────────────┐
   │  K230     │      │   STM32F103C8T6         │      │  6 × Emm42    │
   │ 视觉      │      │   (主控)                │      │  步进驱动     │
   │           │      │                         │      │  addr 1~6     │
   │ T GPIO11 ─┼─────►│ PA3  USART2_RX          │      │               │
   │ R GPIO12 ◄┼──────┤ PA2  USART2_TX          │      │               │
   │ G  GND  ──┼──────┤ GND                     │      │               │
   └───────────┘      │                         │      │               │
                      │ PA9  USART1_TX ─────────┼─────►│ RX (全部)      │
   ┌───────────┐      │ PA10 USART1_RX ◄────────┼──────┤ TX (全部)      │
   │ 2× 舵机    │      │                         │      └──────────────┘
   │ 旋转 PA1 ◄┼──────┤ PA1  TIM2_CH2            │
   │ 夹爪 PA0 ◄┼──────┤ PA0  TIM2_CH1            │      ┌──────────────┐
   └───────────┘      │                         │      │  USB-TTL     │
                      │ PB6  I2C1_SCL ──────────┼─────►│  (调试串口)   │
   ┌───────────┐      │ PB7  I2C1_SDA ◄────────►│      │ PB10 = TX    │
   │  OLED     │      │                         │      │ PB11 = RX    │
   │  SCL PB6  │      │ PB1 / PA7 / PA5 ◄───────┼──┐   └──────────────┘
   │  SDA PB7  │      │ PC13 (板载 LED)         │  │
   └───────────┘      └─────────────────────────┘  │
                                                   ▼
                                            3 个按键 → 3.3V
```

**最关键的三个字：共地。** 所有设备（F103、K230、6 个步进驱动、舵机电源、两个 USB-TTL）的 GND 必须连在一起，否则要么收不到数据，要么乱跳。

---

## 1. K230 ↔ 主控（USART2，115200 8N1）

板载接口：**立创·庐山派 K230 的 GH1.25-4P 串口2 座子**（丝印 `2`，线序 **V-R-T-G**）。

| K230 座子丝印 | K230 芯片脚 | 接到 F103 | 说明 |
|---|---|---|---|
| **T** | GPIO11 | **PA3**（USART2_RX） | K230 发 → 主控收 |
| **R** | GPIO12 | **PA2**（USART2_TX） | 主控发 → K230 收 |
| **G** | GND | **GND** | 必须接 |
| **V** | 5V | **不接** | 接进 F103 会烧 |

- **TX 接 RX、RX 接 TX**，交叉接，不能 TX 接 TX。
- 两边都是 3.3V 电平，可以直接连，不需要电平转换。
- 40Pin 排针的备用点：`pin11 = GPIO5 (UART2_TX)`、`pin13 = GPIO6 (UART2_RX)`；串口3 是 `GPIO50/51`（K230 板）。
- ⚠️ **不要在 PA3 上再挂陀螺仪（JY901）**：它的 `0x55` 二进制帧会把文本行打断。要用陀螺仪就把 K230 挪到 USART3（`SERIAL_USART3_ENABLE = 2` 走 PC10/PC11）。
- ⚠️ **不要在 PA9/PA10 上接任何 ASCII 设备**：那是步进电机总线，`'k'=0x6B` 会被驱动器当成帧尾。

---

## 2. 步进电机总线（USART1，PA9 / PA10）

张大头 Emm42 协议，13 字节帧，**一条总线挂 6 个驱动器**，靠地址区分：

| 地址 | 用途 |
|---|---|
| 1 | 左前轮 FL |
| 2 | 右前轮 FR |
| 3 | 左后轮 RL |
| 4 | 右后轮 RR |
| 5 | 物料电机 |
| 6 | 升降电机（地址 5、6 上电默认失能，要先 `motor_enable_addr()`） |

| F103 | 接到 | 说明 |
|---|---|---|
| **PA9**（USART1_TX） | **所有驱动器**的 `RX` | 一条线并联到 6 个驱动 |
| **PA10**（USART1_RX） | **所有驱动器**的 `TX` | 一条线并联到 6 个驱动 |
| **GND** | 所有驱动器 `GND` | 必须共地 |

- 驱动器供电：按驱动器铭牌（Emm42 常见 24V），**VCC 单独走电源，不要从 F103 取**。
- 6 个驱动地址必须**互不相同**，出厂默认可能都是 1，先用调试模式单独改。
- ⚠️ **烧录时给驱动器断电**：PA9/PA10 同时是串口 bootloader 口，烧写数据会被驱动器当命令收。
- ⚠️ 总线是"一发多收"，驱动器回包带地址，代码里靠地址匹配（`judge_wait()` 里就是查这个）。

---

## 3. 舵机（TIM2，50 Hz / 500~2500 us = 0~270°）

| F103 | 接到舵机 | 用途 | 标定角度 |
|---|---|---|---|
| **PA1**（TIM2_CH2） | 旋转舵机**信号线**（橙/白） | 旋转 | 30° = 夹料位；115° = 放料位（`SERVO_ROT_PLACE_DEG`） |
| **PA0**（TIM2_CH1） | 夹爪舵机**信号线** | 夹爪 | 85° = 松开；115° = 夹紧 |
| **GND** | 舵机 GND | 共地 | |

- 舵机电源：**单独 5V**（两个舵机堵转能上 2 A），用 BEC 或独立 5V 电源。
- ⚠️ **不要用 F103 板上的 5V/3.3V 给舵机供电**，板载 LDO 只有几百 mA，一动就掉压复位。
- ⚠️ 舵机电源的 GND 必须和 F103 的 GND 连起来（共地），否则 PWM 抖动乱转。
- 代码里 `SERVO_INVERT_ROT = 1`（旋转方向已取反），换舵机/换摇臂要重新标。

---

## 4. OLED（I2C1，SSD1306 0x78，400 kHz）

| F103 | OLED 模块 | 说明 |
|---|---|---|
| **PB6**（I2C1_SCL） | SCL | 硬件 I2C，板上一般已有上拉 |
| **PB7**（I2C1_SDA） | SDA | |
| **3V3** | VCC | **3.3V**，不要接 5V（多数模块 5V 也能用，但 3.3V 最安全） |
| **GND** | GND | |

- 上电时 PC13 闪 **1 下** = OLED 有应答；闪 **3 下** = 没应答（查线/地址/供电）。
- ⚠️ PB6/PB7 和 USART3 的默认脚（PB10/PB11）**不是**同一组，别搞混；本工程 USART3 用的是 PB10/PB11，和 OLED 不冲突。

---

## 5. 按键（3 个，下拉输入，按下为高）

| F103 | 按键另一端接 | 当前用途（VISION 模式） | 其它模式用途 |
|---|---|---|---|
| **PB1** | **3.3V** | 发 `circle` | 夹取单步 / 舵机 +10° |
| **PA7** | **3.3V** | 发 `linear` | 夹取连跑 / 舵机 −10° |
| **PA5** | **3.3V** | 发 `stop` | 中止 |

- 按键引脚统一配 `GPIO_Mode_IPD`（下拉输入），**按下读到高电平**。
- ⚠️ **PA12 不能当按键**：它是 USB D+，板上有 1.5k 上拉，会被一直读成"按下"。
- ⚠️ **PA8** 只在 `TURN` 等模式里当低电平按键用（`IPU`），VISION 模式不碰它，可以空着。

## 6. 调试串口（USART3，115200 8N1）

| F103 | USB-TTL | 说明 |
|---|---|---|
| **PB10**（USART3_TX） | 模块 **RX** | 所有 `USART3_Printf` 日志 |
| **PB11**（USART3_RX） | 模块 **TX** | 接收（可选） |
| **GND** | GND | 必须共地 |

- 这个口是"旁路"的，用来看日志、看 `[VISION] TX circle` 这类打印。
- 如果要用无线串口（`tools/chassis_host.py`），就接这里。
- ⚠️ PB10/PB11 在旧代码里也当过按键；接上模块后不要再按那两个"按键"。

---

## 7. 烧录（串口 Bootloader）

| 项目 | 设置 |
|---|---|
| 工具 | STM32CubeProgrammer → UART |
| 接线 | USB-TTL `TX → PA10`、`RX → PA9`、`GND → GND` |
| 波特率 | 115200（CubeProgrammer 可自动） |
| **BOOT0** | **烧写时 = 1**（接 3.3V） |
| **复位运行** | 烧完 **BOOT0 = 0**（接 GND），再按一下复位 |

- ⚠️ 烧录前**给步进驱动器断电**（PA9/PA10 共用）。
- ⚠️ USB-TTL 必须是 **3.3V 电平**的，5V 的可能打坏芯片。
- 烧完后 BOOT0 一定要回 0，否则程序不跑，看着像"烧失败"。

## 8. 引脚占用总表（F103C8T6，LQFP48）

| 引脚 | 功能 | 归属 |
|---|---|---|
| PA0 | TIM2_CH1 PWM | 夹爪舵机 |
| PA1 | TIM2_CH2 PWM | 旋转舵机 |
| PA2 | USART2_TX | **K230 收** |
| PA3 | USART2_RX | **K230 发** |
| PA5 | GPIO 输入（IPD） | 按键：停止 |
| PA7 | GPIO 输入（IPD） | 按键：linear |
| PA8 | GPIO 输入（IPU） | 部分模式当按键（VISION 不用） |
| PA9 | USART1_TX | **步进总线 + 烧录** |
| PA10 | USART1_RX | **步进总线 + 烧录** |
| PA11 / PA12 | — | **不要用**（USB DM/DP，PA12 有 1.5k 上拉） |
| PB1 | GPIO 输入（IPD） | 按键：circle |
| PB6 | I2C1_SCL | OLED |
| PB7 | I2C1_SDA | OLED |
| PB10 | USART3_TX | 调试串口 |
| PB11 | USART3_RX | 调试串口 |
| PC13 | GPIO 推挽（低电平点亮） | 板载 LED / 状态指示 |
| PC14 / PC15 | GPIO 推挽输出高 | 保留（启动即输出高） |

## 9. 上电顺序（建议）

1. 全部设备 **GND 先连好**（这一步不插电）
2. 接 F103 的 3.3V 逻辑电源 → OLED 应亮起，PC13 闪 1 下
3. 接 K230 电源（Type-C），运行 `圆线串口.py`
4. 接舵机 5V
5. 最后接步进驱动器 24V（避免上电瞬间驱动器误动）
6. 确认 **BOOT0 = 0**，按复位

---

## 10. 三条铁律

1. **共地**：F103 / K230 / 驱动器 / 舵机电源 / USB-TTL，GND 全连一起。
2. **TX 接 RX**：K230↔F103、USB-TTL↔F103 都是交叉接。
3. **PA9/PA10 只给步进电机和烧录**：任何 ASCII 文本设备都不能挂上去。

---

## 11. 常见故障对照

| 现象 | 最可能的原因 |
|---|---|
| K230 IDE 有 `[cmd] circle`，但 F103 一直 `CIRCLE WAIT` | PA2/PA3 接反了 |
| F103 一直 `CIRCLE WAIT`，K230 完全没反应 | GND 没连 / 座子 V-R-T-G 线序接错 |
| F103 显示数据但 `NG` 一直在涨 | K230 找不到圆（看 K230 屏幕/IDE），或斜率超门限 |
| OLED 不亮，PC13 闪 3 下 | OLED 的 SCL/SDA 接反或没供电 |
| 按键全都没反应 | 按键没接 3.3V（是"按下为高"，一端必须接 3.3V） |
| 舵机一抖一抖 | 舵机电源和 F103 没共地，或 5V 电流不够 |
| 车不动但 OLED 正常 | 驱动器没使能（上电默认失能）或 24V 没接 |
| 烧录失败 | BOOT0 没置 1，或驱动器还在总线上抢数据 |
