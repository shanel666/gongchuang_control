## 一、每个动作必做清单（judge 之外）

先回答"不依赖寻路代码，一次完整行为除了 judge 还要做什么"。

### 1.1 上电后只做一次（前提）

| # | 事项 | 说明/现状 |
|---|---|---|
| 1 | 外设初始化 | `Serial_Init / Gyro_Init / USART2_Init / USART3_Init / OLED_Init` 等（main.c:236-242） |
| 2 | **使能 4 个电机** | `motor_enable_all()`（N1，你已前移到 main.c:244，工作区待提交）；不使能则松轴，命令发了也不走 |
| 3 | **等陀螺仪第一帧有效** | `Gyro_GetYawCentiDegrees(&yaw)` 返回 1 才算传感器在线（约 100Hz，上电 1 秒内必有）；可 USART3 打印 angle 确认 |
| 4 | 初始 `dir` 与车头朝向一致 | 开环行走靠 dir 状态机；闭环转向不依赖零位，但以后做绝对航向时要把"上电时的当前 yaw"记为基准 |
| 5 | （可选）按键初始化 | PA8 上拉输入必须在主循环**之前**初始化（N2，现在测试块整体注释了，若复用按键要前移） |

### 1.2 每一次平动 / 转动（标准动作链）

```
① 动作函数（qianjin_/houtui_/zuo_/you_/shun_yaw_/ni_yaw_）
   内部：4 条 FD 帧（sync=01 缓存，帧间 5ms 防粘包）
        + 广播 00 FF 66 6B 同步帧（4 轮同时起步）
        + 现在末尾还补了 Delay_ms(5)
② 等待到位：judge()  —— 阻塞轮询 4 电机 0x3A，四轮状态都变 0x03 才返回
③ 闭环转向额外：停稳（Delay_ms(50) + 等一帧新角度）→ 算误差 → 不达标就补转
④ 成功才更新状态：转向后更新 dir；平动后更新当前坐标
⑤ 失败处理：judge/闭环返回 0 → 立即停在本段（OLED 显示错误），不得继续发下一段
```

两个写法细节：

- **标准写法就是 `if(!judge()) return 0;`**，不需要再套一层 `while(!judge()) Delay_ms(50);`——judge() 内部已经是"每轮询一轮 + Delay_ms(5)"的死循环，外层 while 只是多一层壳，行为等价（你横移测试里那种写法能跑，但正式代码不必）。
- **状态只在成功后更新**：`dir = 新朝向` 必须放在闭环/转向成功之后；失败时 dir 保持原值，这样重试或报错时朝向状态才不会骗人。坐标同理。

### 1.3 哪些延时是必要的

| 延时 | 位置 | 结论 |
|---|---|---|
| 帧间 `Delay_ms(5)` | 4 条 FD 之间 | **必要**，手册原话防粘包 |
| 同步帧后 `Delay_ms(5)` | 动作函数末尾 | **保留**，给驱动器留处理时间 |
| 转向后、judge **前** `Delay_ms(1000)` | translation 旧代码 8 处 | **多余**（N21）：judge 本来就阻塞等到位，先白等 1 秒没有任何信息增益，接闭环时删掉 |
| judge **后**、读陀螺仪前 `Delay_ms(50~200)` | 闭环转向 | **必要**：等电机停转 + 车体振荡衰减 + 新帧到达，再读角 |
| 段间 `Delay_ms(1000)` | 你的横移测试循环 | 只是方便肉眼观察，**正式比赛删掉** |

## 二、闭环转向设计

### 2.1 先做相对转角 API，不做绝对航向

```c
uint8_t gyro_turn_delta(int32_t delta_centi);  /* 相对当前航向转 delta，单位 0.01° */
```

- `delta > 0`：逆时针（`ni_yaw_`），陀螺仪角度增大；`delta < 0`：顺时针（`shun_yaw_`）。这是现场 N24/N16 已经验证过的映射。
- 比赛网格每次只转 ±90°，相对 API 足够；**不需要上电零位对齐**，任何时候调用都以"本次调用前的 yaw"为基准。
- 绝对航向 API（`gyro_turn_to`，对应 04 篇设想）以后在相对 API 外面包一层即可，方案见 2.6。

### 2.2 控制流程（一次调用）

```
读起始角 start_yaw（必须有效帧）
   │
   ├─ |delta| ≤ 1°：直接进稳定确认，不发动作
   │
   首发：按 18373 标定发整度开环动作（ni/shun 看符号）
   │   └─ judge() 等到位 → Delay_ms(50) 停稳
   │
   └─ 补转循环（最多 5 次）：
         等一帧【新】角度（Gyro_FrameCount 变化，2 秒超时）
         relative = wrap(yaw − start)
         error    = wrap(delta − relative)
         ├─ |error| ≤ 1° 且连续 3 帧如此 → return 1（成功）
         ├─ 第一次反馈发现往反方向跑了 >5° → return 0（方向接反保护）
         ├─ 补转次数用尽 → return 0
         └─ 按误差补整度（Kp=1，四舍五入，1°~30° 限幅）
             └─ ni/shun 看 error 符号 → judge() → Delay_ms(50) → 再读
```

### 2.3 参数表（先抄这套，现场只需要调容差和 Kp）

| 参数 | 值 | 理由 |
|---|---|---|
| 容差 | ±100 centi = **±1°** | 最小动作是整度（1°≈51 脉冲），±0.1° 物理不可达（N18）；1° 对 90° 网格够用 |
| 稳定帧 | **连续 3 帧** | 滤掉停转瞬间抖动（陀螺仪 100Hz，即 30ms 稳定） |
| 最多补转 | **5 次** | 继承现有两版；正常首发就进容差，5 次是兜底 |
| 单次补转上限 | **30°** | 防止某帧坏数据导致一次大动作冲飞 |
| 反接保护 | 反向 >5°（500 centi） | 第一次反馈朝错方向说明方向位/陀螺仪装反，立刻失败不越陷越深 |
| 停稳延时 | **50ms** | judge 返回后电机刚停；读角前等新帧+车体稳定 |
| Kp | **1（按误差整度补）** | 18373 标定后首发 90° 残差 ≤0.4°，基本不用补；若现场发现一次补转超调，改 0.5（`(abs_error+100)/200`，死代码版写法） |
| 新帧超时 | 200×10ms = **2s** | 复用 `gyro_wait_new_sample()`；陀螺仪掉线/USART2 断线时返回失败 |

### 2.4 关键角度处理

- **一切角度差都要 `gyro_wrap_180()` 包到 ±180°**：从 +179° 转到 −179° 是 +2°，不是 −358°。
- 角度单位统一是 **0.01°（centi）**；只有调电机函数时才换算成整度。
- 整度换算四舍五入：`(abs_error + 50) / 100`，最小补 1°。
- judge 阻塞期间陀螺仪**中断照常收帧**（收帧是 USART2 中断，不依赖主循环），所以不会丢数据；但运动中、停转瞬间的角度不能用，**必须等 judge 返回后的新帧**。

### 2.5 失败情形（都要能在 OLED/USART3 上区分）

| 失败 | 现象 | 排查 |
|---|---|---|
| 起始角无效 | 陀螺仪还没出有效帧 / 没接 | 检查 USART2、Gyro_FrameCount 是否增长 |
| judge 失败 | 堵转/掉线，guard 超时 | 先架空测试；查 0x3A 状态字节 |
| 反接保护 | 首发后角度反向跑 | 方向位/陀螺仪 Z 轴朝向；以 ni 应为角度增大 |
| 新帧超时 | 2 秒没新帧 | USART2 中断、陀螺仪供电 |
| 补转 5 次仍不达标 | 标定值与场地严重不符 / 机械卡滞 | 重测 18373；看每次补转后误差是否在收敛 |

### 2.6 以后接 translation（N19）的做法

现在 translation 里是 `shun/ni_yaw_(90); Delay_ms(1000); judge(); dir=新值;`。闭环接入时分两步：

1. 把每个分支替换成 `turn_to_dir(&dir, 新朝向)`，成功才更新 dir（代码见 4.2）；
2. 方向↔航向表（ni=逆时针=角度增大为正）：**北=0、西=+9000、南=±18000、东=−9000**。
   这是相对差，不依赖陀螺仪零位；反方向继续倒车的现有策略保留（不转 180°）。
3. 再往后要绝对航向（比如"无论当前朝哪，都转到北"），上电时记 `heading_zero = 当前 yaw`，目标角 = `bearing + heading_zero`。

## 三、参考代码副本（可直接抄进 main.c；由你自己写）

> 位置建议：先以 `static` 函数放在 main.c 现有 `gyro_turn_pos_test()` 旁边（`gyro_wrap_180()`、`gyro_wait_new_sample()`、`judge()` 都已存在，直接复用）。
> 本副本**只使用** `Gyro_GetYawCentiDegrees()` / `Gyro_FrameCount` 两个公开接口，**绕开了 N17**（Gyro.h 里那个 extern/static 矛盾的变量），N17 以后整理模块时再修。

### 3.1 宏

```c
/* 闭环转向参数 */
#define GYRO_TURN_TOLERANCE_CENTI   100L   /* 容差 ±1.0° */
#define GYRO_TURN_MAX_CORRECTIONS   5u     /* 最多补转次数 */
#define GYRO_TURN_MAX_CORR_DEG      30L    /* 单次补转上限 30° */
#define GYRO_TURN_STABLE_FRAMES     3u     /* 连续 3 帧进容差 */
#define GYRO_TURN_WRONGWAY_CENTI    500L   /* 首发反向超过 5° 判失败 */
#define GYRO_TURN_SETTLE_MS         50u    /* 停稳延时 */
```

### 3.2 主函数

```c
/* 相对转角闭环：delta_centi 单位 0.01°，>0 逆时针(ni，角度增大)，<0 顺时针(shun)。
 * 返回 1=成功（连续 3 帧在容差内）；0=失败（陀螺仪无效/掉线、judge 失败、反接、补转超限）。
 * 依赖：ni_yaw_/shun_yaw_/judge（motor.c + main.c）、Gyro_GetYawCentiDegrees/Gyro_FrameCount、
 *       gyro_wrap_180/gyro_wait_new_sample（main.c 现有）。 */
static u8 gyro_turn_delta(int32_t delta_centi)
{
    int32_t start_yaw, yaw, relative_yaw, error;
    int32_t abs_error, deg;
    uint32_t last_frame_count;
    uint8_t corrections = 0u;
    uint8_t stable = 0u;
    uint8_t need_first_move = 1u;
    uint8_t check_wrong_way = 1u;

    if (delta_centi > 18000L)  delta_centi = 18000L;
    if (delta_centi < -18000L) delta_centi = -18000L;

    /* 1. 起始角必须有效 */
    if (!Gyro_GetYawCentiDegrees(&start_yaw)) return 0;
    last_frame_count = Gyro_FrameCount;

    /* 2. 目标在容差内就不发动作，直接做稳定确认 */
    if (delta_centi > -GYRO_TURN_TOLERANCE_CENTI &&
        delta_centi <  GYRO_TURN_TOLERANCE_CENTI)
    {
        need_first_move = 0u;
    }

    while (1)
    {
        if (need_first_move)
        {
            /* 3. 首发：按 18373 标定给整度大动作 */
            deg = (delta_centi >= 0L) ? delta_centi : -delta_centi;
            deg = (deg + 50L) / 100L;             /* 四舍五入到整度 */
            if (deg < 1L) return 0;

            if (delta_centi > 0L) ni_yaw_((uint32_t)deg);
            else                  shun_yaw_((uint32_t)deg);
            if (!judge()) return 0;
            Delay_ms(GYRO_TURN_SETTLE_MS);
            need_first_move = 0u;
        }

        /* 4. 必须等停转后的新帧（2 秒超时） */
        if (!gyro_wait_new_sample(&last_frame_count, &yaw)) return 0;

        relative_yaw = gyro_wrap_180(yaw - start_yaw);
        error = gyro_wrap_180(delta_centi - relative_yaw);

        /* 5. 容差 + 连续稳定帧 */
        if (error <= GYRO_TURN_TOLERANCE_CENTI &&
            error >= -GYRO_TURN_TOLERANCE_CENTI)
        {
            if (++stable >= GYRO_TURN_STABLE_FRAMES) return 1;
            continue;
        }
        stable = 0u;

        /* 6. 首发/补转后反向保护：相对角跑到了相反方向超过 5° */
        if (check_wrong_way)
        {
            check_wrong_way = 0u;
            if ((delta_centi > 0L && relative_yaw < -GYRO_TURN_WRONGWAY_CENTI) ||
                (delta_centi < 0L && relative_yaw >  GYRO_TURN_WRONGWAY_CENTI))
                return 0;
        }

        /* 7. 补转次数用尽 */
        if (corrections >= GYRO_TURN_MAX_CORRECTIONS) return 0;

        /* 8. Kp=1 整度补转，限幅 1~30° */
        abs_error = (error >= 0L) ? error : -error;
        deg = (abs_error + 50L) / 100L;
        if (deg < 1L) deg = 1L;
        if (deg > GYRO_TURN_MAX_CORR_DEG) deg = GYRO_TURN_MAX_CORR_DEG;

        if (error > 0L) ni_yaw_((uint32_t)deg);
        else            shun_yaw_((uint32_t)deg);
        if (!judge()) return 0;
        Delay_ms(GYRO_TURN_SETTLE_MS);

        corrections++;
        check_wrong_way = 1u;   /* 补转后也检查一次，防止越补越远 */
    }
}
```

### 4.2 接 translation 的辅助函数（验证完 3.2 再写）

```c
/* dir（1北 2西 3南 4东）对应的绝对航向（centi），ni=逆时针为正：
 * 北=0、西=+9000、南=+18000、东=-9000 */
static const int32_t DIR_BEARING_CENTI[5] = {0, 0, 9000, 18000, -9000};

/* 原地转向到 newdir；成功才更新 *dir，失败保持原朝向 */
static u8 turn_to_dir(u8 *dir, u8 newdir)
{
    int32_t delta;
    if (*dir == newdir) return 1;
    delta = gyro_wrap_180(DIR_BEARING_CENTI[newdir] - DIR_BEARING_CENTI[*dir]);
    if (!gyro_turn_delta(delta)) return 0;
    *dir = newdir;
    return 1;
}
```

替换示意（以 translation 第一分支为例）：

```c
/* 旧：if(dir==2){ shun_yaw_(90); Delay_ms(1000); if(!judge()) return 0; dir=1; }
 *      if(dir==4){ ni_yaw_(90);   Delay_ms(1000); if(!judge()) return 0; dir=1; }
 * 新：把 8 个转弯分支统一改成 */
if (dir != 1) { if(!turn_to_dir(&dir, 1)) return 0; }
```

## 四、现场测试步骤（今晚按这个顺序）

1. **编译前**：确认 `motor_enable_all()` 已在主循环前调用（N1）；不要恢复 PA8 老测试块（它用的是方向相反的死代码版，N16）。
2. **不接线先核方向**：把 `gyro_turn_delta(9000)` 挂在一个测试循环里（可先不按按键，上电直接转一次）。
3. **架空**：车轮离地，转 90°，USART3 观察 relative 变化方向（应为正、停在 +9000 附近），OLED 显示 OK。
4. **落地单次**：地面贴胶带，转 90° 量实际角度；记录最终误差（预期大理石上 ±1° 内、白布上 ≤1.5°）。
5. **四连 90°（最强判据）**：连续转 4 次 +90°，车头应回到原朝向，yaw 回到 0 附近；累计误差超过 2° 说明闭环没在收敛，检查稳定帧/补转方向。
6. **反方向**：测 `gyro_turn_delta(-9000)` 一次。
7. 白布上复测（18373 在白布首发 −0.275°，应一次进容差；若不进，看补转是否正好补到 358.9°→360°）。
8. 通过后再替换 translation 的 8 处开环转向（N19），每改一个分支测一次。

## 五、自检（动手前自测）

1. 为什么首发用 18373 大动作、而不是直接靠补转一点点挪？
   <details><summary>答案</summary>补转次数上限 5 次、单次≤30°，全靠补转最多只能走 150°；大动作 90% 以上的行程靠开环标定（已校准到残差 ≤0.4°），闭环只负责末端修正，又快又稳。</details>
2. 为什么 judge 后还要 Delay_ms(50) + 等新帧？
   <details><summary>答案</summary>judge 返回时电机刚停，车体有振荡，陀螺仪角度还在小幅变化；等 50ms 并拿到停转后的新帧，读到的才是稳定终值，否则可能在稳定帧计数上反复抖动、误补转。</details>
3. `delta = +18000` 和 `-18000` 有区别吗？
   <details><summary>答案</summary>wrap 后等价，朝哪边转都到同一位置；首次进入会夹到 18000，符号决定走哪边。实际比赛按现有策略，反方向直接倒车，不会用 180°。</details>
4. 闭环跑起来后，`gyro_wait_new_sample` 一直超时（返回 0），最可能的原因？
   <details><summary>答案</summary>陀螺仪没在收帧：USART2 接线/供电、Gyro_FrameCount 不增长；judge 期间中断是正常工作的，不影响。</details>
5. 第一次落地就返回失败（TURN ERR），OLED 上怎么判断是哪一类？
   <details><summary>答案</summary>建议在函数各失败点临时给不同显示码（如 E1 起始角、E2 judge、E3 反接、E4 超时、E5 补转超限）；排查顺序见 2.5。</details>
