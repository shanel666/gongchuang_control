## 3. 关键机制结论

### 3.1 电机应答机制与程序校验是否合理（02 篇分析，🟢 结论）

电机每条命令都会应答（手册 p.40）：FD/F3 类返回 `[addr][code] 02 6B`（02=正确），异常返回 `E2`（参数错）/`EE`（格式错）。

| 环节 | 程序做法 | 结论 |
|---|---|---|
| 发送运动/使能/同步帧 | **盲发，不检查 02 应答** | 可接受：后面有 `judge()` 到位轮询兜底，命令丢失会超时失败；但无法区分"没收到"和"收到但执行失败" |
| 到位判断 `judge()` | 查 3A 状态，要求回包 `[addr][3A][03][6B]`，**地址+功能码+状态三重匹配**，每轮询前清缓冲 | 🟢 合理。0x03 = bit0 使能 + bit1 位置到达，严格相等还隐含"无堵转(bit2/3)、无掉电标志(bit7)"，比手册示例的 `status & 0x02` 更严格（手册 p.74） |
| 帧解析 | 0x01~0x04 当帧头；普通回包收 4 字节查帧尾 0x6B；**0x36 回包按 8 字节收（查 `RxPacket[7]==0x6B`，e2cf205 修复，N3 关闭）** | 🟢 解析已支持长帧；位置值的单圈/多圈语义仍取决于固件（N13） |
| 校验码 | 出厂默认固定 0x6B，**不是真校验和** | 总线上误码无法检出；场地干扰小可接受，若出现误动作再考虑切 XOR/CRC（手册 p.40） |

### 3.2 同步运动机制（🟢 手册 p.37 证实）

4 条运动帧第 12 字节发 `01`（缓存不动），最后广播 `00 FF 66 6B` 同时起步；帧间 `Delay_ms(5)` 是手册原话"延时几毫秒防粘包"。否则 4 个电机排队约 25ms 起步会跑偏。
2026-10-16 版六个动作函数在同步帧后也都补了 `Delay_ms(5)`（电机离开同步帧有处理时间，现场调试加入），已随 0b510b7/2d0a2ce 提交。

### 3.3 旋转方向（✅ 2026-10-16 现场定性）

| 函数 | 四轮方向位 | 物理效果（左前/右前/左后/右后） | 命名 |
|---|---|---|---|
| `qianjin_` | 1 0 1 0 | 前 前 前 前 | 一致 |

### 3.4 陀螺仪闭环现状（04 篇，🟢 代码事实）

- **2026-10-17：统一闭环 API 已落地并现场验证**：设计稿的 `gyro_turn_delta()` 已由 Mike 抄入 main.c 的 `__MIKELIN_DEBUG` 条件编译区（20bc802，N28）；**现场确认陀螺仪左转（逆时针）为正方向，90° 转向很正**（18373 首发即进 ±1° 容差，未触发补转）。参数同设计稿：容差 ±1°、连续 3 帧、补转上限 5 次、单次限幅 30°、反接保护 5°、停稳 50ms、新帧超时 2s。
- **帧解析**：11 字节 `55 53 …`，yaw 在 [6,7] 小端有符号，`角度(0.01°)=raw×18000/32768`；校验和 = 前 10 字节求和取低 8 位。只解析 0x53 角度帧；`volatile` 共享 + `Gyro_FrameCount` 帧计数；USART2 中断逐字节喂解析器（Gyro.c / Serial.c:285-324）。
- **PA8 内联测试版（2026-10-17 已随 20bc802 整体注释删除）**：PA8 触发、目标 +90°；离散迭代——发位置脉冲 → judge 等到位 → 读 yaw → 按误差补，最多 5 次；Kp=1、容差 ±1°；角度差用 `gyro_wrap_180()` 包到 ±180°。其有效逻辑已被 `gyro_turn_delta()` 取代。
- **死代码版 `gyro_turn_pos_test()`（main.c:140-206）**：通用任意角，Kp=0.5、容差 ±0.1°、连续 3 帧稳定、必须新帧、首次反馈反向 >5° 判失败、单次 ≤30°。其中 ±0.1° 小于最小动作 1°（约 51 脉冲/度，18373 标定后），**实际不可达**，生效版放宽到 ±1° 是合理的。
- 结论：**相对转角 API 已完成验证，但还没接入路径行走**——translation() 的 8 处转弯仍是开环（N19 剩余工作）；统一 API 与接入方法见《设计稿_闭环转向（参考副本）》。

### 3.5 主程序三层架构（05 篇，🟢 代码事实）

- 路线层（死代码）：`switch(step)`，每 case 一个 `go_to(目标)`，成功 +1、失败跳 99、100 完成；
- 调度层：`go_to()` 调 `path_plan`（07 篇）得关键点，逐段调 `translation`，指针维护当前坐标；
- 编排层：`translation()` 朝向状态机 `dir`（1北/2西/3南/4东），反方向不转 180° 而直接倒车；只接受同行/同列点；
- 动作层：motor.c；到位：`judge()` 轮询 4 电机状态 0x03，guard 60000 轮（约 3 小时，只防死机）。
- 当前 main() 结构（2026-10-17，20bc802）：main.c 已加条件编译开关 **`__MIKELIN_DEBUG`**（N28）——定义时编译调试 main（初始化 + `path_planner_init()` + `motor_enable_all()` + `gyro_turn_delta(9000)` 后空转）；不定义时编译原生产 main（含路线 switch，PA8 测试块已全部注释）。**工作区唯一未提交改动就是把 `// #define __MIKELIN_DEBUG` 打开**（正在调试）。N1/N23 已随 20bc802 关闭；恢复路线时关掉宏即可。

### 3.6 到位等待时序（judge 轮询，02 篇细讲，🟢 代码+手册 p.73-74）

- 动作函数（qianjin_ 等）只是"发命令"：4 条 FD 帧（sync=01 缓存）+ 广播 `00 FF 66 6B` 同时起步，**函数返回时车刚开始动**；
- "走完没有"由**电机内部闭环**判定：驱动器按目标脉冲+加减速曲线自行走完并自停，置状态位 Prf_TF（bit1，位置到达）；
- 单片机在 `judge()` 里**阻塞轮询**：轮流对 4 个电机发 `0x3A`，回包状态字节运动中 = 0x01（仅使能）、到位 = 0x03；四电机都 0x03 才返回 1；
- 因此 `qianjin_(1000)` 之后、`houtui_(1000)` 的命令发出去之前，程序卡在 judge()，电机不会"转到一半接到新命令"；同步帧管"同时开始"，judge 管"全部走完再进下一段"；
- 代价：等待期间单片机除了 OLED 刷新外什么都不做（陀螺仪不更新、不响应新指令），后续任务复杂时应改为非阻塞状态机（新增设想，低优）。

## 5. 改进设想（评估后记录）

### 5.1 距离/角度换算改成带参数宏（🟢 建议采纳，低风险）

现状：`mm * PULSE_PER_100CM / 1000u` 在 6 个函数里各抄一遍，旋转公式抄 2 遍。改为：

```c
/* 注意：参数与整个表达式都要加括号，参数显式转 uint32_t 防溢出 */
#define MM_TO_PULSE(mm)   ((uint32_t)(mm) * PULSE_PER_100CM / 1000u)
#define DEG_TO_PULSE(deg) ((uint32_t)(deg) * PULSE_PER_360DEG / 360u)
```

好处：标定值只改一处；以后四轮若要分别标定，可扩展成 `MM_TO_PULSE_W(mm, factor)`。横移 -5% 偏差（N25）也可直接用同一思路给横移专用系数。
截断误差 <1 脉冲（≈0.08mm），无需四舍五入；旋转同理（18373 下每度约 51.04 脉冲）。

### 5.2 judge 状态判断是否改为位掩码
现用 `status == 0x03` 严格相等。改成 `status & 0x02` 更宽松（有别的标志位也算到位），但会丢掉"堵转即失败"的保护——**维持现状**，但应在超时分支里打印状态字节，便于现场区分"没到位"和"堵转"。

### 5.3 运动命令发送后是否校验 02 应答
当前盲发。可在 `motor_send_*` 后等 1~2ms 收 `[addr][code]02 6B`，失败重发一次。当前有 judge 兜底，优先级低；若现场出现电机丢命令，再做。

### 5.4 统一陀螺仪转向 API（🟢 04 篇后建议，接手闭环时做）

合并两个版本的优点，替换 translation() 里的 8 处开环转向：

```c
uint8_t gyro_turn_to(int32_t target_yaw_centi);  /* 转至绝对航向 */
```

**2026-10-17 进展：相对转角 API `gyro_turn_delta()` 已按设计稿落地（20bc802，__MIKELIN_DEBUG 区），实测左转（逆时针）为正、90° 转向准确**。设计稿 → `docs/设计稿_闭环转向（参考副本）.md`。原设计要点（实现时已照抄）：

- 方向映射：现场已定（N24/N16），误差 >0（角度需增大）→ `ni_yaw_`，误差 <0 → `shun_yaw_`，只保留一套；
- 容差 ±1°（N18），最多 5 次；保留死代码版的：新帧检测（帧计数对比）、连续 3 帧稳定、首次反馈反向保护、单次修正上限 30°；
- Kp 取 1 或 0.5 现场调（18373 标定后首发 90° 残差 ≤0.4°，首发基本就能进容差，闭环主要消累积）；
- 顺带修 N17（extern/static 一致性；副本只用 getter API 绕开）；
- 初始航向：上电时把当前 yaw 记为"北"（或对齐 PATH_INITIAL_DIR），后续所有转弯按绝对航向，避免误差累积。
- **剩余清单（2026-10-17）**：①写 `turn_to_dir()` 并替换 translation 的 8 处开环转向（N19）；②闭环移出 __MIKELIN_DEBUG 区、成为生产代码；③做绝对航向版本（需定上电零位）。
